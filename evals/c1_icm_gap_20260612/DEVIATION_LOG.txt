D2. INSTRUMENT FIX (the C0 halt condition fired, 18:24-18:26 local):
    First C0 run (M=2000, symmetric start, design's outcome definition
    "Y=1 iff seat has chips when the loop breaks at n_alive<=3"):
      survive counts [1027, 921, 982, 963, 960, 1026], capped=0,
      tainted=0, survivor-sum histogram {3: 1885, 2: 109, 1: 6}.
      Seat-averaged error = -0.01008, SE ~ 0.00093, t ~ -10.8 ->
      CI excludes 0 -> the pre-registered INSTRUMENT FAILURE branch.
    Diagnosis (exact): 115/2000 games terminate with FEWER than 3
    chip-holders (simultaneous multi-bust hands at the 4-alive bubble:
    109 double-busts, 6 triple-busts). The raw definition then pays
    <3 seats, while the real format always pays exactly 3 (a player
    busting simultaneously with another still finishes 3rd if their
    hand-start stack was bigger). Deficit (109*1 + 6*2)/12000 =
    0.010083 matches the measured offset to 4 decimals. This is a
    definitional artifact of the design's Y, not a seam/blind-guard/
    capping bug; play_sng_game's hero_net shares the same semantics
    (noted as a finding for the owner, out of scope here).
    Fix (applied before Tier 1): Y_i = 1 iff seat i finishes in the
    top 3, with elimination order tracked during the rollout;
    simultaneous busts are ranked by hand-start stack (bigger stack
    finishes higher), ties -> lower seat index finishes worse. This is
    the standard tournament rule and the quantity MH ICM actually
    predicts. Both definitions are recorded per state; the corrected
    one is primary, the raw one is reported as a sensitivity line.
    Consequence: the C0 seat-averaged test becomes structurally exact
    (sum of ITM flags = 3 in every non-excluded game), so the binding
    C0 checks are taints=0, caps<=2%, and the position-effect
    sensitivity probe. C0 was re-run after the fix.
