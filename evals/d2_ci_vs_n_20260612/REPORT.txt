METHOD & ASSUMPTIONS
  - Wilson 95% score intervals throughout; "half-width" = half the CI width,
    so "within +-Xpp" means half-width <= X percentage points.
  - VPIP convention matches src/nlhe/opponent_db/db.py::_session_vpip:
    denominator = non-hero dealt seat-hands; numerator = seat-hands with >=1
    voluntary preflop frame_diff action. decision_record rows excluded per
    data/opponent_db/README.md.
  - i.i.d. Bernoulli assumption on seat-hands. This ignores within-session and
    within-opponent correlation (same opponents repeat across the session's
    seat-hands), so true CIs are somewhat WIDER than reported. Treat every
    threshold below as a best-case (lower-bound) sample-size requirement.
  - Projection rate: 19 opponent-observed hands/session (task-stated live
    rate). Observed rate over the 11 raw-record sessions is 23.5/session;
    both are used in Q4.
  - Depth subset (Q3) uses pre-hand start stacks, available only for anchored
    hands: 314/420 raw-record hands. Mild selection toward clean-frame hands.

BIAS FLAGS (every number below inherits these; fix queued Windows-side, OQ-1)
  [B1] VPIP is an OBSERVED LOWER BOUND: frames sample every few seconds, so
       limp/call actions falling between frames are lost and checks are
       invisible. All CIs here cover the observed rate, not the true VPIP.
       True VPIP >= every point estimate below.
  [B2] Folds are systematically undercounted: forensic re-measure (RESEARCH_MAP
       d3, 2026-06-12) found the stale `folded` flag misses ~100% of fold
       events (0/241 chip-proven preflop folds flagged). Consequence: ANY
       fold-frequency statistic (fold-vs-shove, fold-to-3bet) is currently
       uncomputable, not just noisy — its numerator is structurally ~0. Only
       chip-moving frequencies (VPIP, raise, call, all-in rates) are
       trustworthy lower bounds. Marked [B2] where it bites below.
  [B3] Per-opponent CIs with p-hat near 0 look deceptively narrow: a Wilson CI
       around a numerator suppressed by [B1] is precise about the OBSERVED
       rate while the true rate may sit above the upper limit. Low-p-hat
       "decision-grade" keys in Q2/Q3 should be discounted accordingly.
