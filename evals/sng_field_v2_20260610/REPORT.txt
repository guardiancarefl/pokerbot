DECOMPOSITION OF THE GAP (v1 29.2 vs live ~15-37, levels <=5):
1. TIGHT-FIELD ARTIFACT — DOMINANT. Swap only the opponents (Shanky field -> hero-clones,
   identical harness/hpl/seeds): 29.2 -> 16.2 hands/game, right on the live distribution.
   Shanky profiles bust ~2x slower than realistic opposition; games then grind into L6-L8
   where blinds force terminations.
2. HERO-BUST CENSORING — SECONDARY. v1 hands/game counts the FULL TABLE to the 3-alive
   terminal, including hands after hero busts. The live record stops when hero busts.
   Replay probe (exact v1 seeds, hero_net cross-check 0/2000 mismatches): table 27.1 ->
   hero-observed 20.1 vs killphil; 34.4 -> 28.5 vs ticketmaster; 29.4 -> 28.8 littlegreen;
   34.4 -> 33.7 vs mtt. Effect -1 to -7 hands depending on hero bust rate.
3. ESCALATION CADENCE — MINOR. Live shows ~5.7 hands/level pooled (range 3-14) vs hpl=5:
   harness escalates slightly FASTER than live, which shortens games — it cannot explain
   v1 running long. Not the driver. (One live session ran ~9/level; live levels are
   time-based, so hpl is an approximation by design.)
4. HARNESS ISSUE — RULED OUT for game length: chip conservation + 3-alive terminal verified
   (calibration row, 0 tainted, hands/game distribution sane), replay determinism exact.

C3 TRAINING-DISTRIBUTION CONSEQUENCE (the actual finding): harvesting states from
vs-Shanky-field games OVERSAMPLES high-level/short-stack states that live play never
reaches — 19.1% of v1 hands are at L6+, live corpus has ZERO hands above L5. A C3 harvest
should either (a) draw from self-play-paced games (16 hands/game, level distribution matches
live), or (b) importance-weight/truncate the vs-field games at the live level distribution.
"Looks fine" it is not: an unweighted v1 harvest trains ~1 in 5 decisions on states with
no live counterpart.
